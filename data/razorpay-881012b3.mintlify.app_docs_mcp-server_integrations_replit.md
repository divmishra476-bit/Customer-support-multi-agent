# Connect Razorpay MCP Server to Replit

> Connect the Razorpay MCP Server to the Replit Agent from the Integrations settings and authorise it using OAuth.

Replit Agent connects to external tools through MCP. Add the Razorpay Remote MCP Server from the Integrations settings and authorise it using OAuth.

## Add the Razorpay MCP Server

1. Log in to your Replit account.
2. On the left panel, click **Integrations**.
3. Scroll down to **MCP Servers for Replit Agent** and click **Add MCP Server**.
4. Set **Display Name** to **Razorpay** and **MCP Server URL** to `https://mcp.razorpay.com/mcp`, then click **Test & Save**.
5. Replit tests the connection to the MCP Server URL. Once the test is complete, click **Authorise Server**, sign in with your Razorpay merchant credentials, and grant access on the consent page.
6. A new MCP server is added with the name **Razorpay** and the status **Active**.
7. To use the Razorpay MCP server, click **Home** and type **/razorpay** to invoke it for your commands.
