# User Roles & Workflows

> Create, edit, delete and manage user roles on the Razorpay Dashboard.

You can customise pre-existing user roles, modify the permissions and set up workflows on the Dashboard. After sign up, the following roles are immediately available:

* Administrator
* Human resources
* Payroll
* Report Viewer
* Reimbursements
* Chartered Accountant

<img src="https://razorpay.com/docs/build/browser/assets/images/xpayroll-user-roles.jpg" alt="User roles available on the RazorpayX Payroll Dashboard" width="800" />

Provide special access, like [administrator permissions](/docs/payroll/quickstart), to the people in your team. You can also [create custom roles](#create-user-roles). This is available with the [Elite and Enterprise Plans](/docs/payroll/plans) only.

Explore how you can assign user roles, create custom roles and more.

## User Role Actions

Following are the user role actions available to you on the Dashboard.

### Create User Roles

To view the user roles available on the Dashboard:

1. Log in to the [Payroll Dashboard](https://payroll.razorpay.com/dashboard).
2. Navigate to **Settings** from the left menu.
3. Go to the **User Roles** section. Click **CREATE/EDIT ROLES**.

   On the User Roles & Permissions page, you can:

<Tabs>
  <Tab title="Modify existing roles">
    1) Click the user role. The **Manage Role** page opens.
    2) Under each section, select the permissions applicable for the role.
           <img src="https://razorpay.com/docs/build/browser/assets/images/xpayroll-edit-user-role.jpg" alt="Select or clear the permissions to modify user role" width="600" />
    3) Click **SAVE CHANGES** to finalise the changes.
  </Tab>

  <Tab title="Create new roles">
    1. Click **+ CREATE NEW ROLE**.
    2. You can either:
       * Create a blank role and set permissions manually.
       * Use the existing user roles and permissions as a template.

    <img src="https://razorpay.com/docs/build/browser/assets/images/xpayroll-create-custom-roles.jpg" alt="Create user roles on Dashbaord" width="800" />

    1. On the **Manage Role** page, add a role name, set/modify the permissions and click **SAVE CHANGES**.
  </Tab>
</Tabs>

1. Enter the OTP you receive at your registered email address/authenticator app and authorise the changes.

You have successfully created a user role.

### Assign User Roles

To assign the user roles you have created:

1. Log in to the [Payroll Dashboard](https://payroll.razorpay.com/dashboard).
2. Navigate to **People** and select the employee you want to assign the role to.
3. In the employee's profile, go to **User Roles & Permissions** → **EDIT**.
4. Select a role to assign from the drop-down list.
   <img src="https://razorpay.com/docs/build/browser/assets/images/xpayroll-assign-role.jpg" alt="Assign a role to employee" width="800" />

You have successfully assiged a new role to the employee.

<Warning>
  **Watch Out!**

  Ensure that the person you provide special access/role/permissions to is already a part of your organisation's payroll. Know more about [adding people to Payroll](/docs/payroll/quickstart#add-all-employees).
</Warning>

### Edit User Roles

You can modify the permissions of all the available user roles.

1. Log in to the [Payroll Dashboard](https://payroll.razorpay.com/dashboard).
2. Navigate to **Settings** from the left menu.
3. Go to **User Roles** → **CREATE/EDIT ROLES**.
4. Click the role you must modify. The **Manage Role** page opens.
5. Select or clear the check boxes to modify the permissions for that role.
   <img src="https://razorpay.com/docs/build/browser/assets/images/xpayroll-edit-user-role.jpg" alt="Select or clear the permissions to modify user role" width="600" />
6. Enter the OTP you receive at your registered email address/authenticator app and click **SAVE CHANGES**.

You have successfully modified the user role.

### Delete User Roles

When the role is no longer required, you can delete the role from the Dashboard in the following way:

1. Log in to the [Payroll Dashboard](https://payroll.razorpay.com/dashboard).
2. Navigate to **Settings** from the left menu.
3. Go to **User Roles** → **CREATE/EDIT ROLES**.
4. Click the role you must modify. The **Manage Role** page opens.
5. Click **DELETE ROLE**.
   <img src="https://razorpay.com/docs/build/browser/assets/images/xpayroll-delete-role.jpg" alt="Delete user role on Payroll Dashboard" width="800" />

You have successfully deleted a user role.

<Warning>
  **Watch Out!**

  You can delete custom user roles only.
</Warning>

## Setup Workflows

With user roles, you can also set up workflows on the Dashboard. For example, you can allow one employee to only edit the payroll, and allow another employee to only finalise the payroll.

To set up workflows:

1. Log in to the [Payroll Dashboard](https://payroll.razorpay.com/dashboard).
2. Follow the steps to [create custom role](#create-user-roles) for both these actions. You must create separate user roles for each of them.

You have successfully created a user role workflow. [Assign the user role](#assign-user-roles) to the specific employee in your organisation.

## View Collaborators

You can also view the list of people who have special user roles assigned to them. To do so, navigate to **Settings** → **Collaborators**.

<img src="https://razorpay.com/docs/build/browser/assets/images/xpayroll-view-collaborators.jpg" alt="List of employees with special permissions in Payroll." width="800" />

Once your users are all setup, you can start configuring their documents, leaves and attendance in [Leave Setup](/docs/payroll/leaves).
