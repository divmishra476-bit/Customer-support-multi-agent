Payroll provides comprehensive solutions for managing Cost to Company (CTC) components and various compensation elements. The system enables organisations to structure employee compensation effectively while ensuring compliance with statutory requirements and maintaining transparency in salary administration.

<AccordionGroup>
  <Accordion title="Features">
    | Feature                      | Description                                                                                           | Example                                                                                                                                            |
    | ---------------------------- | ----------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
    | **CTC Component Management** | Comprehensive view and management of all salary components that constitute the total Cost to Company. | Centralised view of all components (basic, allowances, deductions, employer contributions and so on) replacing error-prone spreadsheet management. |
    | **Recurring Deductions**     | Add, edit or delete recurring deductions with proper authorisation and audit trails.                  | Systematic management of recurring deductions with clear categorisation.                                                                           |
    | **FBP Allocation**           | Flexible Benefits Plan allocation based on employee eligibility and choices.                          | Employees can view and select benefits within FBP limits for tax optimisation.                                                                     |

  </Accordion>

### Accessing Employee Compensation

Navigate to **People → Employee's Name → Pay** to access an employee's compensation details. The compensation dashboard displays a complete overview of the employee's pay structure.

### Compensation Overview

The main compensation screen presents:

* **Annual CTC** - Total cost to company displayed prominently (₹36,00,000 in the example).
* **Visual Breakdown** - Pie chart showing the distribution between fixed, variable and other CTC components.
* **Key Metrics**:
  * Recurring deduction amount
  * Perquisites value
  * Flexi components allocation
