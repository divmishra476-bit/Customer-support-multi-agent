# All Webhook Events

Given below is the complete list of webhook events for [Payments](#payments-webhooks), [Partners](#partners-oauth-webhooks) and [Payouts](#payouts-webhooks).

<Warning>
  **Watch Out!**

  RazorpayX Lite is currently not available for new merchants. To set up a new RazorpayX account, refer to [Current Account](/docs/x/account-types/current-account).
</Warning>

|                             | [subscription.activated](/docs/webhooks/subscriptions#subscription-activated)                             | Sent when the subscription moves to the active state either from the authenticated, pending or halted state. Existing invoices that were already generated are not charged.                                                                 |

|                             | [subscription.completed](/docs/webhooks/subscriptions#subscription-completed)                             | Sent when all the invoices are generated for a subscription and the subscription moves to the completed state.                                                                                                                                                                                                                                                                         |
|                             | [subscription.updated](/docs/webhooks/subscriptions#subscription-updated)                                 | Sent when a subscription is successfully updated. |                             | [subscription.pending](/docs/webhooks/subscriptions#subscription-pending)                                 | Sent when the subscription moves to the pending state. If the payment fails again, the Webhook is triggered again.                                                                                                                                       |
|                             | [subscription.halted](/docs/webhooks/subscriptions#subscription-halted)                                   | Sent when all retries have been exhausted and the subscription moves from the pending state to the halted state. |                             | [subscription.cancelled](/docs/webhooks/subscriptions#subscription-cancelled)                             | Sent when a subscription is cancelled and moved to the cancelled state.                                                                                                                                                                                                                                                                                                                |
|                             | [subscription.paused](/docs/webhooks/subscriptions#subscription-paused)                                   | Sent when a subscription is paused and moved to the paused state.                                                                                                                                                                                                                                                                                                                      |

|                             | [payout.initiated](/docs/webhooks/payouts#payout-initiated)                                               | Triggered when the payout moves to the processing state when the payout is created or from the queued state when sufficient funds are available to process the payout.                                                                                                                                                                                                                 |

This happens when the payout is processed by the contact's bank.                                                                                                                                                                                                                                                                 |
|                             | [payout.updated](/docs/webhooks/payouts#payout-updated)                                                   | Triggered whenever there is a change in the payout entity. For example, when we receive the UTR for the payout from the bank.<ul><li>For NEFT transactions, this webhook is fired within 90 seconds.</li><li>For IMPS and UPI transactions, this webhook is generally fired immediately.</li></ul>                                                                                     |
|                             | [payout.reversed](/docs/webhooks/payouts#payout-reversed)                                                 | Triggered whenever a payout fails and the amount is returned to your business account.                                                                                                                                                                                                                                                                                                 |
|                             | [payout.failed](/docs/webhooks/payouts#payout-failed)                                                     | Triggered when a payout is failed because the beneficiary bank OR NPCI OR processing partner bank is down. |                             | [payout.downtime.resolved](/docs/webhooks/payouts#payout-downtime-resolved)                               | Triggered when a payout downtime is resolved. |                             | [payout\_link.cancelled](/docs/webhooks/payout-links#payout-link-cancelled)                               | Triggered whenever a payout link moves to the cancelled state. |                             | [payout\_link.rejected](/docs/webhooks/payout-links#payout-link-rejected)                                 | Triggered whenever a payout link moves to the rejected state. |                             | [payout\_link.expired](/docs/webhooks/payout-links#payout-link-expired)                                   | Triggered whenever a payout link moves to the expired state.
