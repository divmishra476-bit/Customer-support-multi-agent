# Connect Razorpay MCP Server to ChatGPT

> Connect the Razorpay MCP Server to ChatGPT using the official Razorpay app from the ChatGPT app directory and the OAuth flow.

Razorpay is available as an official app in the ChatGPT app directory. As with Claude, you do not need to set up a custom connector. Install the listed app and authorise it to get started.

## Connect the Razorpay App

1. Open ChatGPT and browse the apps from the **Apps** entry in the sidebar, or go to **Settings** → **Apps** → **Add More**.
2. Locate and select the **Razorpay** app from the directory.
3. Click **Connect** and complete the OAuth flow with your Razorpay merchant credentials. Enable sync if prompted.
4. In the chat composer, type **@Razorpay** and select the app from the drop-down. Alternatively, click **+** → **More** to add it to the conversation.
5. Ask a question, such as: **Find all refunds raised by customers in the last 30 days**.

<Info>
  **Handy Tips**

  On ChatGPT Business or Enterprise plans, a workspace admin may need to enable or deploy the app for the team from **Settings** → **Apps**. Individual members can then connect it using self-service setup.
</Info>
